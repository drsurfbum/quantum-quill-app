	•	Associated Locations: where it appears or originates
	•	Associated Characters / Groups: who uses or worships or is affected by it
	•	Associated Events: key events tied to this element (invention date, major crisis)
	•	Short Notes: 1-line summary
	•	Overview: rich-text description
	•	Category-Specific Fields (dynamically shown once category chosen):
	•	Flora: Habitat, Growth Behavior, Uses (edible, medicinal), Threats, Lifecycle
	•	Fauna: Habitat, Diet, Behavior, Lifecycle, Domestication Status, Threat Level
	•	Religion/Ritual: Core Beliefs, Deities, Followers, Ceremonies, Taboos
	•	Mythology: Origin Story, Major Myths, Symbolism, Cultural Impact
	•	Item/Artifact: Creator/Origin, Materials, Powers/Abilities, Known Owners, Current Location
	•	Language: Spoken/Written, Grammar Notes, Unique Phrases, Script Appearance, Region
	•	System: Purpose, Key Components, Participants, Effects on Society (e.g. Economic System: currency, trade routes)
	•	Entertainment: Type (Music, Game, Storytelling), Cultural Role, Popularity, History
	•	Clothing: Materials, Design Motifs, Occasion, Social Significance
	•	Food: Ingredients, Preparation, Cultural Significance, Availability
	•	Disease/Medicine: Symptoms, Transmission, Cure/Treatment, Historical Outbreaks
	•	Law/Politics: Governing Body, Legal Codes, Enforcement, Historical Changes
	•	Professions: Training Requirements, Tools, Societal Role, Status
	•	Technology: Inventor, Power Source, Functional Description, Limitations, Adoption Level
	•	Astronomy: Celestial Type (Planet, Star, Comet), Observations, Mythological Significance, Effects (eclipses, tides)
	•	Weather: Regional Patterns, Seasonal Variations, Effects on Population/Environment
	•	Details / Lore Hooks: freeform list of small notes (idioms, rumors, anecdotes)
	•	Research Links: Title, Type, URL, Notes Taken?
	•	Status: Common, Rare, Extinct/Defunct, Legendary, etc.
	•	Tags: cross-category tags (e.g., “Bioluminescent,” “Ancient Tech,” “Forbidden Knowledge”)

Agent Behavior: On new World Element creation, immediately ask for Category. Once selected, surface the relevant prompts for subfields. If user picks a category not in master list, confirm if they want to add it. For subcategory options (e.g., under Flora or Technology), offer common defaults but allow custom input.

3.6 Details
	•	Linked Element: Which element(s) this detail attaches to (Character, Location, Event, World Element, Group)
	•	Type (optional): Note, Quote, Idea, Lore Hook, Reminder
	•	Short Description: 1-line summary
	•	Content: multi-line text
	•	Visibility: Public / Private / Draft
	•	Tags: e.g., “Foreshadowing,” “Plot Hook,” “Continuity Check”

Agent Behavior: When user creates a Detail, ask: “Which primary element(s) does this note relate to?” Encourage linking. Prompt for type if helpful. If the linked element doesn’t exist yet, offer to create a stub.

3.7 Research
	•	Title
	•	Source Type (single-select): Article, Book, Video, Image, Website, Map, Interview, Other
	•	URL or Reference
	•	Linked Element(s): where this research applies
	•	Notes Taken? (checkbox)
	•	Summary Field: short summary of findings
	•	Tags / Topic: e.g., “Gravity Research,” “Medieval Weaponry,” “Asteroid Mining Techniques”

Agent Behavior: Prompt user for source type early. When linking to elements, allow multiple. Offer to store summaries within the entry. Suggest tagging for easy filtering later.
