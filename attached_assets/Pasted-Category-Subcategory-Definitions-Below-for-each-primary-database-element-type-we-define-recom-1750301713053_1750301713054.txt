Category & Subcategory Definitions

Below, for each primary database (element type), we define recommended subcategories or fields that guide organization. The Replit agent should prompt or enforce these when users create/edit entries.

3.1 Characters
	•	Primary Category / Role (single-select):
	•	Protagonist
	•	Antagonist
	•	Supporting Character
	•	NPC / Minor Character
	•	Cameo / Background
	•	Affiliation / Faction (multi-select from Groups & Races)
	•	Archetype / Profession Tag (multi-select; e.g., Pilot, Scientist, Merchant)
	•	Status (single-select): Alive, Deceased, Missing, Unknown
	•	Era / Timeline Period (if you use named eras)
	•	Importance Level (optional: e.g., Main, Secondary, Tertiary)
	•	Custom Tags (for anything outside the above, but encourage reuse of existing tags)

Agent Behavior: When user creates a character, first ask: “What role does this character play?” Offer the controlled list. Then ask for affiliations (link to Groups & Races). If they type a new affiliation, confirm adding it to Groups & Races.

3.2 Groups & Races
	•	Category (single-select):
	•	Species / Race
	•	Organization / Faction
	•	Tribe / Clan
	•	Government / Political Body
	•	Company / Guild
	•	Parent Group (optional; for hierarchies, e.g., “Galactic Coalition” → “Outer Rim Faction”)
	•	Status: Active, Defunct, Secret/Hidden
	•	Home Location: link to Locations
	•	Notable Members: link to Characters
	•	Era Established / Dissolved (optional timeline fields)
	•	Custom Tags: e.g., “Mercenary,” “Religious Order,” etc.

Agent Behavior: On new group/race entry, after naming it, ask: “Is this a Race/Species, Organization, or other?” Then adapt fields accordingly (e.g., for Race: ask for homeworld or biological notes; for Organization: ask for founding date, leadership structure).

3.3 Locations
	•	Type (single-select):
	•	Planet
	•	Moon
	•	City / Settlement
	•	Building / Structure
	•	Region / Biome
	•	Station / Ship (if you treat vehicles as “locations” in some cases)
	•	Dungeon / Ruin
	•	Other (with custom label)
	•	Parent Location: (e.g., City → Planet; Hangar → Space Station)
	•	Environment / Biome (multi-select or single-select depending on how fine-grained: e.g. Desert, Ice, Urban, Underwater)
	•	Status: Inhabited, Abandoned, Ruined, Under Construction
	•	Significance Tag (multi-select): Capital, Trading Hub, Military Base, Sacred Site, etc.
	•	Coordinates or Map Reference (if you have a mapping feature)
	•	Tags: for quick filtering (e.g., “mining colony,” “smuggling port”)
	•	Era / Timeline Relevance (optional: when it was founded or destroyed)
	•	Short Notes: 1-liner description
	•	Custom Fields: (only after category chosen; e.g. for Planet: gravity, atmosphere; for Building: floor count, purpose; for Ship: capacity, manufacturer)

Agent Behavior: When a user creates a new Location, first ask: “What type of location is this?” Then show relevant subfields or prompts. If they choose “Other,” ask them to specify a custom subtype and consider adding to taxonomy if reused later.

3.4 Events
	•	Type (single-select):
	•	Conflict / Battle
	•	Discovery / Invention
	•	Diplomacy / Treaty
	•	Personal Milestone (Birth, Death, Promotion, Betrayal)
	•	Catastrophe / Disaster
	•	Festival / Ceremony
	•	Migration / Exploration
	•	Other (with custom label)
	•	Date / Era:
	•	Year (required if known)
	•	Month/Day or fictional calendar fields
	•	Approximate flag if date uncertain
	•	Location(s): Link to one or more Locations
	•	Characters Involved: Link to Characters, with optional role tags (“Leader,” “Witness,” etc.)
	•	Groups / Factions: Link to Groups & Races participating
	•	Outcome / Significance Tag (single-select or multi-select): e.g., “Victory,” “Defeat,” “Alliance Formed,” “Cataclysm,” “Turning Point”
	•	Short Summary: 1-line
	•	Detailed Description: multi-line rich text
	•	Visibility / Status: Canonical, Rumor/Legend, Hypothetical
	•	Tags: e.g., “War,” “Scientific Breakthrough,” “Rebellion”

Agent Behavior: Prompt early for date info (even if partial) so the future timeline dashboard can slot it correctly. When linking Characters or Locations not yet in the database, offer to create stubs.

3.5 World Elements
	•	Category (single-select from your list):
	•	Flora
	•	Fauna
	•	Religion/Ritual
	•	Mythology
	•	Item/Artifact
	•	Language
	•	System (economic, social, magical system)
	•	Entertainment
	•	Clothing
	•	Food
	•	Disease/Medicine
	•	Law/Politics
	•	Professions
	•	Technology
	•	Astronomy
	•	Weather
	•	(Potentially more in future; prompt to confirm addition)
	•	Subcategory / Specific Type (optional multi-select or free text if needed): For example:
	•	Flora → (Herbaceous, Tree, Fungal, Aquatic)
	•	Fauna → (Predator, Prey, Domestic, Wild)
	•	Technology → (Weapon, Transport, Communication)
	•	Religion/Ritual → (Cult, Festival, Prayer, Offering)
	•	Language → (Dialect, Script, Slang)
	•	Parent Element (for hierarchies: e.g., “Solar Deity Worship” ← “Religion/Ritual”)
	•	Associated Locations: where it appears or originates
	•	Associated Characters / Groups: who uses or worships or is affected by it
	•	Associated Events: key events tied to this element (invention date, major crisis)
	•	Short Notes: 1-line summary
	•	Overview: rich-text description
	•	Category-Specific Fields (dynamically shown once category chosen):
	•	Flora: Habitat, Growth Behavior, Uses (edible, medicinal), Threats, Lifecycle
	•	Fauna: Habitat, Diet, Behavior, Lifecycle, Domestication Status, Threat Level
	•	Religion/Ritual: Core Beliefs, Deities, Followers, Ceremonies, Taboos
	•	Mythology: Origin Story, Major Myths, Symbolism, Cultural Impact
	•	Item/Artifact: Creator/Origin, Materials, Powers/Abilities, Known Owners, Current Location
	•	Language: Spoken/Written, Grammar Notes, Unique Phrases, Script Appearance, Region
	•	System: Purpose, Key Components, Participants, Effects on Society (e.g. Economic System: currency, trade routes)
	•	Entertainment: Type (Music, Game, Storytelling), Cultural Role, Popularity, History
	•	Clothing: Materials, Design Motifs, Occasion, Social Significance
	•	Food: Ingredients, Preparation, Cultural Significance, Availability
	•	Disease/Medicine: Symptoms, Transmission, Cure/Treatment, Historical Outbreaks
	•	Law/Politics: Governing Body, Legal Codes, Enforcement, Historical Changes
	•	Professions: Training Requirements, Tools, Societal Role, Status
	•	Technology: Inventor, Power Source, Functional Description, Limitations, Adoption Level
	•	Astronomy: Celestial Type (Planet, Star, Comet), Observations, Mythological Significance, Effects (eclipses, tides)
	•	Weather: Regional Patterns, Seasonal Variations, Effects on Population/Environment
	•	Details / Lore Hooks: freeform list of small notes (idioms, rumors, anecdotes)
	•	Research Links: Title, Type, URL, Notes Taken?
	•	Status: Common, Rare, Extinct/Defunct, Legendary, etc.
	•	Tags: cross-category tags (e.g., “Bioluminescent,” “Ancient Tech,” “Forbidden Knowledge”)

Agent Behavior: On new World Element creation, immediately ask for Category. Once selected, surface the relevant prompts for subfields. If user picks a category not in master list, confirm if they want to add it. For subcategory options (e.g., under Flora or Technology), offer common defaults but allow custom input.
