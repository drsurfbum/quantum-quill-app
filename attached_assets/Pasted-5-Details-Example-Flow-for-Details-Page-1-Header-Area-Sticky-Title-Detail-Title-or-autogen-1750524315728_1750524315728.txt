5. Details

Example Flow for Details Page
	1.	Header Area (Sticky)
	•	Title: Detail Title or autogenerated from summary (e.g., “Foreshadow: Broken Beacon”)
	•	Badge: Type (Note, Quote, Idea, Lore Hook)
	•	Save/Delete icons.
	2.	Main Column
	•	Core Link (expanded initially):
	•	Linked Element(s): select one or more primary entries (Character, Location, Event, World Element, Group)
	•	Type selector: Note, Quote, Idea, Reminder, Foreshadow
	•	Short Summary (one-liner)
	•	Content (expanded initially):
	•	Multi-line text area for the note or quote
	•	Context & Usage (collapsible):
	•	Explanation: How/when to use this detail (e.g., “Drop this hint in Chapter 3”)
	•	Visibility: Internal only or visible to collaborators
	•	Relational Suggestions (collapsible):
	•	Based on linked elements, suggest linking related entries (e.g., if linked to Character X, suggest linking to Event Y).
	•	Archive/Resolution (collapsible):
	•	Status: Open, Resolved, Archived
	•	Outcome notes if resolved
	3.	Sidebar
	•	Classification:
	•	Type, Status
	•	Links Summary:
	•	Chips for primary linked entries
	•	Tags:
	•	e.g., “Foreshadowing,” “Plot Twist,” “Continuity Check”
	•	Timestamps & Actions:
	•	Created/Updated, Archive toggle
	4.	Post-Save Suggestions
	•	“Apply this Detail to another linked entry?”
	•	“Convert to Event or Research if it becomes more substantial.”

Prioritization (≤150 words)

Details capture loose ideas, foreshadowing, random notes—crucial for creativity but easily lost in flat lists. Focus first on linking each detail to at least one primary element (Character, Location, etc.), categorizing type (Note, Foreshadow, Reminder), and a concise summary. This ensures every detail is anchored in the relational network. Content area can be freeform. Keep advanced fields (context usage, resolution status) collapsed until needed. Well-linked Details allow you to track plot hooks, avoid contradictions, and retrieve inspiration quickly. A lightweight yet linked Details template prevents clutter and promotes iterative world-building.
