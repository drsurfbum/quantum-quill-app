No real manuscripts or hosted test accounts were used. Physical iPad Safari/Home Screen and the actual software-keyboard compositor remain unverified. Video publisher/region restrictions can require the visible external fallback; this release does not claim new end-to-end playback verification of every video. The existing bundle-size advisory remains.

Production dependency audit still reports one high Zod advisory and 33 moderate advisories, with no critical production advisory. Dependencies are unchanged. The existing request-structure budget runs before authentication/schema validation and rejects oversized/deep collections, including legacy JSON strings; its regression checks pass. This is an existing mitigation, not a claim that the dependency advisory is resolved. Keep dependency maintenance as a separate reviewed follow-up rather than applying a major upgrade during this UI release.
